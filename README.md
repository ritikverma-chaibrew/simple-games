# Small Games Club

## Snake

Open [index.html](index.html) in a browser to play. No install or server is needed.

- Steer with the arrow keys, WASD, the on-screen direction pad, or a swipe on the board.
- Press Space or Escape to pause and resume.
- Eat the fruit to grow and score points. Hitting the wall or yourself ends the round.
- Your best score is saved in this browser.
